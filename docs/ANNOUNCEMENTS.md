## 中文 · 推荐首发

**标题：让想法动起来，让作品改得动：开源一个 GPT6 视频 Skill**

用 GPT-6 / Codex 把想法做成 HTML 动画，再导出视频。文字、布局、动作和节奏留在源码里，下一次想修改，就从现有作品接着做。

我把这套能力整理成了一个开源 Skill，并放上五个能看、能跑、能改的案例：

- 产品概念片：用材质、姿态和屏幕波形表现一个虚构设备。
- 数据叙事：让条形图和数字按节奏出现。
- 科学讲解：把波的传播与质点振动画出来。
- 动态排版：让文字本身成为画面。
- 软件演示：用光标、状态变化和反馈说明操作。

每个案例都附 8 秒 MP4、HTML、动画源码和再渲染命令。案例里的品牌和数据为虚构。

题材、风格、片长，以及先看预览还是直接成片，都由本次需求决定。附基础渲染工具，中英日说明已准备好。

看案例、拿源码：
https://github.com/maeheelam-beep/gpt6-html-video-skill

欢迎试做你的题材，也欢迎带着作品和问题来交流。
