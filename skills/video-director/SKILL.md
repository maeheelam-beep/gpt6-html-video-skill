# GPT6 HTML 动画视频

帮助当前用户把想法、脚本、设计稿或素材做成HTML动画与视频。每个作品的内容、审美、结构和工作方式都由本次需求决定。技能只提供可复用的技术能力与设计判断，不携带历史用户的题材、偏好、项目案例或制作习惯。

## 需求驱动

首先理解用户想表达什么、给谁看、在哪里使用、期望什么结果。用户已经提供的主题、时长、比例、参考风格、素材、声音和交付方式直接采用；只询问真正影响结果的缺项。允许用户简短输入、充分指定或让你自由发挥。

创意由需求生长：可以是一镜到底，也可以多镜头；可以安静、热烈、精确、写实或抽象。不要预设镜头数、转场数量、配色、节奏、字幕、配音、画幅或片长。仅在信息不足且不值得打断时选合理假设，说明假设并允许修改。不要把技术脚手架的默认值当作用户偏好。

工作方式同样由用户决定。要先讨论就先讨论；要分镜或预览确认就在所指节点停下；要直接成片就在授权范围内完成。已有项目的修改聚焦用户提出的问题，保留无关设计。不要把某个历史项目的步骤或检查频率强加给所有作品。

## HTML动画实现

按目标选择最合适且足够简单的技术：HTML/CSS适合排版与界面，SVG适合清晰图形，Canvas适合逐帧合成，WebGL适合确有需要的空间与材质。可混合使用，保留可编辑源码。主体连续性、字体可读性和动作意义比堆叠特效更重要。

浏览器预览与离线导出应对应同一时间状态。需要确定性渲染时使用render(t)等可seek接口，资源与字体就绪后再采集帧。现有动画框架可以保留；不要为了固定代码结构重写可靠实现。

按需读 [implementation.md](references/routes.md) 了解可选能力，不必调用所有技能或安装所有依赖。工具、文件路径和运行入口见 [runtime.md](references/runtime.md)。输入素材与来源见 [media.md](references/media.md)。

## 工具是选项

本技能附带可选的原生工具，便于环境检查、创建空工程、渲染与审片。也可以使用用户项目已有工具链。

```text
node <本技能>/scripts/studio.mjs doctor
node <本技能>/scripts/studio.mjs init <新目录> --duration <用户所需秒数> --size <宽>x<高> --fps <帧率> --audio none|required
node <本技能>/scripts/studio.mjs render <项目目录> --out film.mp4
node <本技能>/scripts/studio.mjs qa <影片路径> --project <项目目录>
node <本技能>/scripts/studio.mjs review <项目目录>
```

init只产生技术起点，不是成品模板；实现用户内容后标记starter=false。有声片render需传实际音频文件。project.json只为附带工具记录该作品规格，不限制用户使用其他工程结构。技能适配Codex/GPT6的工具环境，不更改模型、账号或推理设置。

## 按作品验证和交付

检查与当前内容相关的问题：表现是否符合需求、文字是否可读、动作是否连续、素材是否就绪，以及输出是否符合用户规格。实际查看渲染结果；需要时采样关键时刻、转场、局部或最终编码帧，选择足以发现问题的检查密度，不规定每个项目必须走同一组步骤。可选审片工具见 [review.md](references/review.md)。

用户需要字幕、声音、透明背景、循环、源码或特定格式时，按要求实现；不要自动给所有作品添加这些元素。只宣称实际做过的验证。按用户需要交付可观看的视频、可编辑HTML工程及必要说明；明确尚未完成或依赖外部工具的部分。

整合来源与依赖边界见 [sources.md](references/sources.md)。
