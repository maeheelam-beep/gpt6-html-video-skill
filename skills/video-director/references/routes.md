# 可选实现能力

从用户目标选择技术和工具，而不是从技能列表倒推作品。下列是可复用能力，不是必经阶段；只加载当前需要的少量资料。doctor可以发现实际安装路径，技能缺失时可采用其他合适实现。

| 当前需要 | 可选能力 |
|---|---|
| HTML/CSS/SVG/Canvas动画、声音与视频导出 | motion-showreel的运行工具与对应技术参考 |
| 用户指定某种Lemo风格 | lemo-opuscar及选中的风格资料 |
| 可seek镜头、音乐/文字同步 | code-mv-render的确定性时间系统 |
| 某种局部界面动效 | ui2v-motions中合适且许可清楚的素材或技法 |
| UI、系统或卡片展示 | phone-ui-demos、win11-ui-demos、card-theater、stacked-data-cards的合适组件 |
| 图形、流程、图表、课程或分镜呈现 | flowchart、dynamic-archify、network-protocol-viz、web-video-presentation等对应能力 |
| 用户明确选择的排版或分镜风格 | swiss-shot-demos、video-shot-demos、ppt-animation等参考，不自动继承其示例风格 |
| 图像素材、角色或纹理 | 可用的宿主图像工具；需要时参考gpt-image-2或opus-video-skills |
| 三维或复杂浏览器合成 | 当前可用的WebGL/Three.js或其他引擎，按实际依赖评估 |
| 渲染/批量/质量检测的其他方案 | HyperFrames、FrameProof等实际可用工具；导航技能存在不等于引擎已安装 |

整合的是工具和方法，不是所有上游流程规则。用户当前指令决定风格、细节、互动节点和交付范围。保持一种有意图的整体设计，可以借用多种技术，但不为展示工具而拼接无关效果。
